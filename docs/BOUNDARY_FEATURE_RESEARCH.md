# 人工黄金边界的离线特征研究

本研究从人工确认的黄金裁切保护线进入原 TIFF 有界邻域，包含检测器尚未发现的画面边界。目的在于找出能够
区分真实接触与竞争解释的像素证据；不能把模型预测相符、局部梯度最大或经常出现在成功样片上的
特征直接当成边界权限。运行时继续使用现有放置模型与联合搜索，黄金坐标只用于离线研究和评价。

H 先验证、验收，再推进 W 实现。W 可以预先收集离线数据，但不能因此宣称 H 已解决。
准确性、reference 权限和发布验收仍以 [ARCHITECTURE.md](ARCHITECTURE.md) 第 14 节及
[MANUAL_ANNOTATION.md](MANUAL_ANNOTATION.md) 为准。

## 数据与证据分层

- 按 `source_sha256` 聚合全部 count、Frame、H/W 物理线和局部窗口。同源任务不得进入不同开发分组，
  同一共享 H 线不能因跨越多张照片而成为多份独立证据。Frame 身份为同源 start/end line ID 对，不能
  跨 count 使用 ordinal 代替物理身份。
- `directly_visible`、`visible_content_limit` 和 `human_width_estimate` 分别统计。后两类不能混入
  清晰边缘正例；估计线附近偶然出现强梯度也不能反向改变人工依据。Blank 没有可见边界，不补造样本。
- 人工 line 没有逐位置可见性标注。由四条物理线交点得到的是几何采样范围，不代表整个范围都能看见
  边缘。保留逐位置数据、空间缺测和沿线覆盖，不能用平均值掩盖短而可靠的证据。
- 源截断处保留物理线和采样缺测；TIFF 外无像素，不向内钳位，也不把 TIFF 外缘补成真实成像边。
- 当前黄金集均属开发数据。按源确定的五组仅供后续开发比较，不能把重新分组包装成未见来源验证。
  未来独立封存样片遵循既有验收合同。

## 原图邻域测量

唯一离线入口：

```bash
tools/verify diagnostic --gold-boundary-features --axes HW \
  --output-root Test/gold_analysis/gold_boundary_features
```

`--axes H` 是默认值；`--sample-id` 可重复指定，但选择任一 task 都会纳入它的完整 source group。
执行前只读核对全部当前确认记录、审阅凭据、原 TIFF SHA 与 tracked cohort；不执行黄金提升。
输出限于忽略的 `Test/`，记录 cohort、源码、源图及产物哈希和依赖版本，不构成检测或性能 receipt。

每个非空 Frame 的 H/W 物理边界段使用 24 个等距内部位置；每处按原图法向采样，向内为正。
法向半径为对应 Frame 跨度的 5%，限定为 16–256 像素；切向取五条相邻剖面。采样采用原 TIFF
像素的双线性插值，消除半像素取整随镜像方向改变的问题，完整插值邻域越界时明确缺测。
原始 16 位 RGB 除以 65535 保留数值，不做局部拉伸、ICC 变换或把 JPEG 当像素来源。

保留 RGB 剖面及固定偏移网格上多个尺度的内外灰度、RGB 差、对立颜色差、法向/切向纹理、
变化相对于局部起伏的比值、近远变化极性和外侧平滑性。尺度为可完整容纳的 2/4/8/16/32 像素窗口。
这些都是描述量，不是接触分数、材料身份或自动选线规则；固定网格也不穷尽任意位置与倾斜解释。
24 个固定位置与五条局部剖面不能证明整条边界的材料连通性，也可能漏过很短的可见证据。没有测到
显著变化只能描述此次采样，不能据此把人工直接可见线降为不可识别；这类位置需要原图局部加密检查。

## 已核实的特征解释限制

用户对 `bounded_competitors.png` 的局部判读确认：S047、S003、S064 的蓝线是准确接触位置，S016
的蓝线不准确。这说明相对冻结黄金线向内偏移并不必然侵入真实画面；当前研究不能把偏移方向当成
真实接触的正负标签。人工黄金线不具有精确到 1 px 的真实接触定位含义，但仍严格约束最终裁切
不得进入其内侧。三处蓝线准确不意味着可以把最终裁切直接放到蓝线上，也不意味着黄金基线错误。
用户此次接触位置确认仅覆盖所展示窗口，不外推为整条共享边或其它照片的确认，不改写冻结黄金坐标。

开发集 S016 的有界原图邻域存在亮外层、暗边带与画面内容的多层结构，蓝线落在画面内部。它可以
作为此次局部判读中的错误接触例子；其余三处不能再作为错误接触反例。黄金保护线为高精度接触
搜索提供可靠的有界邻域指引，不能要求其坐标本身的梯度最大，也不能把邻近最强梯度自动命名为照片边界。

这些案例只解释为什么单点强度和梯度排序不足以完成接触判定，不产生样片分支或运行时阈值。
统计比较仍需覆盖全部来源及低反差、灰尘、片夹边、内部强线和突出点的反例；当前稀疏采样不是
这些干扰的完整语义标注集。

## 正反例与验收顺序

先按源比较黄金边附近的特征分布和不同空间位置，再检查邻近竞争解释。相对冻结基准的方向性越界
是现有 accuracy 合同下的几何差异，不能直接转换为真实画面侵入或接触错误标签。内外偏移都先作为
未判定比较位置；只有独立原图证据或明确人工判读支持时，才赋予相应局部研究标签。灰尘、片夹边、内部强线、
突出点和低反差边界需要结合原图有界邻域及原始几何逐项判读，不能仅凭特征高低自动命名。
语义尚不清楚的例子保留为未判定，研究判读不修改人工 reference。
既有特征排序统计仅描述冻结基准与偏移位置的数值差别，不是正负例区分率；仅由偏移方向推断的
接触负标签须撤销并重新评价，不能通过增加运行时容差或样片特例消除差异。

研究始终分开三个层次：黄金保护线指导离线搜索；原图像素支持高精度真实接触位置及其不确定性；
最终裁切输出仍按既有黄金包含与外扩预算合同验收。真实接触线不自动等于最终裁切线。运行时不得
读取黄金坐标来选边或逐样片补偿；边界识别准确与输出满足保护约束必须分别验证。

特征评估同时保留弱正例和强反例，按源汇总，避免把同源大量窗口当成独立成功次数。单特征有区分
趋势不等于可以授权边界；必须检查特征组合在材料变化、缺测、短证据、杂点与竞争解释下的失败情况。

H 的接触证据需要进入同一位置、倾斜、上下配对、有界高度和空间覆盖求解。模型缩小可行域，像素
提供独立证据；未解决的 raw 解释必须传到联合求解，不能靠删除歧义点或退回单侧高度推断变成唯一解。
经真实样片及反例验证后，才替换现机制中被覆盖的路径，并验证完整生产 CLI 的准确性、安全性和回归。
H 验收前不进行 W 运行时改造。W 后续还须分别检查每张照片的边归属以及 separator、contact、overlap、
partial exposure 和 source truncation；同一 contact 物理线可有两个相反的内侧角色。

本工具只测量、记录研究数据，不增加运行时检测器，不调整 Gate、reference、格式先验或发布条件。
正式性能验收仍留到发布阶段。
