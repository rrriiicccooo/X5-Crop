## V5（开发中，尚未发布）

### 行为边界

- 长轴 baseline 与 anchor windows 保留原始峰的完整来源和单峰选择规则；桥接测量可在同灰度、
  同 baseline 重放该规则，Cross 连续证明继续只接受自身反向分峰。Cross 来源／原生纹理先完成，
  新长轴来源只用剩余资源，超界不丢原测量。结构规划和捕获分开计费，连固定预检都无法容纳时保留明确
  未尝试状态；不能清零已执行工作。来源记录不新增角色、连接、序号或输出权限；报告 schema 为 132。
- Aperture 双轴保护按各边自己的位置偏差与完整斜率求四组 affine 最小闭合上界，减少跨边组合产生的
  额外保护。原始线族、raw 区间、像素保护及固定窗口仍完整核验；enclosing support 沿用原共享上界。
- 开发排序增加固定预算预筛对照：复用原 source 分组模型与分数，仅从原预算通过的已有候选中选择，
  无符合者则弃选。全体池与 canonical 描述池分别保留结果，不进入 Runtime 或自动准入；分析 schema 为 v7。
- 新增同源开发报告的 base Cross 保留审计，分别核对原始测量、tracking、拟合、family／membership
  账本和 solver。旧原点仍在而整组解释停止生成，或新组仅为旧 raw 的 superset 时，明确保留未证实
  的关联／资格缺口；采样后候选减少不被当作物理排除。该工具不进入 Runtime 或改变自动批准。
- 原生连续桥接分别保留选峰 OR 可信组与正负 AND 连通响应；必需原峰及密集原峰的完整组都须在
  原 query 内观察到两侧。局部强梯度接通而可信组已截断时保持 unavailable，不转授连续资格、
  不删除旧解释。三份 mask、组索引与完整 flank 重放共同计入原资源池。
- 完整源测量在同次调用内共享相同输入的累计和，容量先由原 source 池预留，容量不足时保持原计算；
  数值、原峰、完整区间和权限不变。连续性规划共享原峰索引与 trace 投影，只对实际进入规划的边预留
  重工作，失败义务仍保留；没有新增约束时复用原登记，省去重复验证。metadata 与原点规划分阶段计费，
  两阶段峰值完整保留。
- 原生 Cross 连续桥接补测已有直接边的尾段：沿用完整原灰度 baseline 与原峰选择器，逐行保留密集
  响应、全部峰、来源与物理区间。完整原峰链和同状态物理域都通过后，向原 binding 附加独立连续
  约束，实际参与 Cross 准入、精修及保护；原角色、raw、family 和照片序号权限保持。
  弱信号、多峰、缺测或预算不足保持 unavailable。整个 batch 先预检同源工作与临时量；普通及
  development 报告使用同一 base registration，重放完整像素证据及资源。
- 粗测支撑边与精测原生边通过完整原峰来源核对：同源、同核、同归一化信号、完整峰组与同一原峰
  才能关联。独立连续原生线及所有 observation／原 atom／family／membership 延续都通过核验后，
  完整原生区间进入原 coarse 的同状态物理域和局部保护，并扩展实际已测连续域；域外仍保留完整方向保护。
  原 coarse 身份、raw 区间、支撑用途和竞争成员保留，不新增像素、拟合或 Cross 配额。
  普通报告保存独立证明与完整 base 输入，开发报告重放来源、查询及全部工作。
- 同一 phase pass 中，完整连续格点拟合输入相同时复用原数值结果，最多保留 16 项；每个 seed 的
  身份、匹配、邻接实现、成员和最终权限仍独立核验。Lookup、实际拟合、复用与峰值项数分别记账，
  临时内存仍使用原 source 上限。该机制不减少新 Cross raw union 的真实
  拟合数量，不改变 S028 的 `3R/2R` 整批准入限制。
- V5 只有一条 current-only production path。输入 format 必须由用户提供，count 可确认默认值或明确指定；
  空曝光格保留，任何必需 slot 不安全都会使整张 source 进入 `needs_review`。
- 每条 source 使用共同 W/H 和固定 `1.1W × 1.1H` 原图坐标窗口，四边 5% 留边包含基础保护；程序只选择
  位置。可见内容、物理边界、typed evidence、source/lane 安全与人工 reference 继续按架构合同核验。
- 长轴归属已确定、短轴直接解释集合完整时，以全部成员各自 H 的保守包络校准整源输出高度，避免已有
  直接测量仍沿用默认 H。原 Cross 输入、成员、原生边界与完整保护保持；校准先于预算，全部成员仍须
  通过共同输出权限、内容、范围和预算检查。单份条件提案、单侧推断及不完整集合不获得该资格。
- 独立 source W 收窄时，即使 canonical W 不变，缺失边界的 model/full 区间仍同步更新；原生边界、
  phase 状态与真实 runner 保留。已选唯一 enclosing-support pair 的中心先验按相同资格规则重新绑定
  当前 4 源观察集合，向外量化区间为 `[-0.003H, +0.010H]`。
- Nominal Grid 保留已证明接触边界对相邻 END/START 的两项角色绑定；共享边界仍是一份物理观察，
  不增加 rank。无合法 contact 的重复绑定继续拒绝，schema 或 solver 错误不再误报为物理 Grid 冲突。
  保留的 native 双边宽度完整区间若与格式物理范围不相交，资格阶段即拒绝该映射；原有安全诊断提案
  继续保留。区间相交的局部变化不被代表点或拟合 W 强行排除。
  共享边恢复合法拓扑竞争后，多解 source 进入 Review，保留完整竞争证据与未闭合原因。
- Nominal 输出联合投影重放全部原生位置锚点、共同尺度及邻接约束，避免边际 hull 组合出无法同时
  成立的保护状态；role 差分消去共用 local prefix，避免重复计算同一不确定性。直接边界坐标和完整
  区间保持。不同合法 Contact/Overlap topology 不再因支持数或 coverage 分离被当作唯一解。
  源截断 Review 类优先保留独立获权原生证据更完整的解释，投影失败与
  反证原样保留；无权弱线和相关重复观察不能提高该优先级。
  Phase 与 topology 歧义均按两份 retained fit 各自补全原生局部边界、传播联合约束与 Cross 支撑域；
  不共享另一解释的 W、不取消歧义或物理反证。
  独立原生 Review 按成功原生坐标、成功校准 Grid、失败原始解释分别保留四个端点角色类；不同几何
  依据不再因共享端点类别互相覆盖。失败与反证保留，原规范竞争及自动权限保持独立；新增实际重建
  工作逐次计入有界 receipt。
  最后补入原生边界后，保留解释分别重建自身邻接证明。唯一已登记伙伴的条件照片序号、原物理身份
  与完整宽度反证进入报告；不补 phase anchor、不增加 rank、不借用另一解释的 source W。新增工作
  固定至多两份并计入账本；已否定的 runner 不使未保留的其它解释自动消失。
- 只有真实 TIFF 外缘允许 source clipping；内部 authority 边界不能用缩小窗口绕过。Deskew 只在批准后
  整理，不参与检测或 Gate。Debug Analysis 复用同次检测事实，不取得裁切或自动输出权限。
- 正式 TIFF 只在整张 source 通过安全准入后发布；输出先写 staging，再原子发布到全新目录，保留既有目标。

### 验证边界

- 长轴来源按原 baseline 对账，两轴原 trace 的信号 SHA、原选峰、完整物理区间及标量响应须可精确重放。
  反例覆盖错误分峰、移除 baseline 来源、耗尽资源及剩余预算不足；新增来源不能挤掉已登记 Cross 原峰或
  原生纹理，也不能靠省略已执行预检来满足上限。
- 逐边保护闭合使用独立二维线性规划核对不等式最小解，覆盖负余量、像素下界、轴交换及非收缩斜率乘积的
  反例；原联合角点、连续中间状态和 raw endpoint 准入仍参与验证。精度收紧本身不证明样片预算或资格恢复。
- 独立 Review 的初始尺寸、canonical 的实测校准与照片序号证明分别核验。相同的代表框不保证相同的
  保护或固定窗口；较大诊断窗口、源边截断分类及预算通过均不能代替独立归属证据。此澄清不改变 Runtime。
- 预算预筛保留 incomplete／未评估状态，分别核对 task 与去重 source 的选择、不安全和弃选计数。
  反例覆盖预算通过仍不安全、没有通过方案时禁止回退、同源 count 变体、heldout 标签不参与选择，以及
  篡改规则、结果或准入权限。现有 Cross H 相容域不冒充完整 raw 几何或完整曝光证明。
- 保留审计覆盖仅改本地编号、物理区间／信号 SHA／native texture 变化、缺失峰来源、重复原点身份、
  分散点、完整 superset、只有 family／membership 账本及精确 solver raw 保留；并发写入不能覆盖已有产物。
  审计 0 只表示具名 base raw 可对账，不证明完整集合、输出资格或发布通过；
  输入错误与需复核分别使用不同退出码。
- 峰组反例分别覆盖 AND 分量完整而 OR 组左／右截断、完整 flank 但物理区间越组，以及原始来源组
  不完整。正确的完整组仍可改变正式 Cross 资格；截断组不再提供该资格。普通报告先通过正向重放，
  再验证只改变 OR mask、保留原正负响应／峰／来源／工作与旧约束的语义篡改会被拒绝；缺字段或删组也拒绝。
- 端点诊断同时记录原选峰像素上的 native16 响应和附近区域的响应，不把附近强线重选为原边界。
  新锚点只来自冻结原始点与 query，完整原引用、极性、缺失身份和资源均可对账；原像素命中不能
  代替物理边界、照片序号或终端证明。诊断 contract 更新为 v2，分析记录／汇总 schema 为 36／37。
- 邻接材料与短边连续性分别核验身份权限：两端均未绑定的三区域材料带，即使严格落在某个完整
  Frame 内，也不能单独否定该照片解释；材料角色不证明照片序号。短边的局部角色或 pair 纵向权限
  不能替代自身的整域连续证据；原峰完全对应也不能绕过这一条件。补充两类独立反例，生产权限保持。
- 已登记 TOP／BOTTOM 峰在原始 16 位 RGB 上增加独立二维纹理测量，保留原灰度坐标、梯度、tone
  和一维纹理。完整核、原峰、源域及工作按当前 schema 重放；不能用窗口截断、重新选点或未计读取
  取得角色。两侧全部局部核先共同预检，仍受原 source 像素和临时内存上限约束。
  局部 opposite 只有通过同一 direct-pair owner 的完整纵向资格才能停止整源补边，防止短局部边取消
  原会生成的竞争。二维纹理不证明片段身份、同照片或真实终端；原型中因该早退出出现的自动通过
  不计作覆盖收益。
- 当 phase 与 Cross 同时有备选时，分别保留已有 phase runner 与 primary phase 自身的 Cross runner，
  避免同一位置竞争覆盖短轴竞争。每条 lane 最多增加一份完整诊断提案，连同有条件提案总数不超过 4；
  去重、原始拟合身份、投影与预算工作按同一报告核验，不新增 Cross 求解或自动输出权限。
- 组合方向 ID 从自身有序 observation 列表重建，再按同一严格双射对账；保护原生 ID、角色、位置、
  原始点与全部角度字段继续严格检查，不把完整方向字符串当作可任意改名的编号。
  已选唯一外框的中心校准按原资格规则绑定当前 4 源集合（v20），数值区间保持不变，不按批准或预算筛选来源。
- 短轴归属枚举在 required 和至多一个 pending 原子的完整 union 已核验时直接复用同一证明；
  同一 scope 的过滤与极大性扩展按完全相同的原始 mask 复用已完成的 True／False 核验，真实
  whole-union 仍实际计算。查询、实际求交、按用途及布尔值的复用分别记账，原每条 lane 的 4096
  次实际核验上限保持；缓存先预检原 source 内存，返回时显式清空。多原子的联合域、极大性、
  全集物化预检和逐成员输出权限继续独立检查；省去重复求解不等于缺证消失。
  同次 Cross 配对按原 binding 和完整域按需复用中性覆盖，历史成员的资格检查与报告共用自身
  已核验的 Cross 摘要，避免再次扫描同一 raw 并集。
- 短轴四项仍需人工检查：S002 的局部 50 点唯一选中、22 条歧义与 3 条无候选全部保留；新增有效精修
  已入 solver，但半径内 239 个候选点中 143 个尚未进入注册 line，不能把选点覆盖当作完整关联。
  S015 的条件完整线与 canonical 碎片的同 trace 原始点可以不同，不能转授身份及长轴支撑。
  两项现有 8／37 个完整归属组均已投影，未发现现成完整组漏传；S062 的外侧角色反证继续阻断。
  S028 在同一正式输入上以 3,334 次实际核验完成原需 5,380 次的搜索，原 4,096 上限不变；
  5,380 次查询包含 1,059 次 True 与 987 次 False 精确复用，175 个完整极大组保持。
  后续 174 个新增唯一 raw union 仍未通过整批拟合预检：TOP 的稳健／约束计数为 69／47，超过
  66／44；BOTTOM 为 177／142，超过 105／70。两侧均不新增拟合，不输出前缀；全局 512 observation
  与 4096 pair/fit 上限仍独立适用，未执行不代表通过。本轮未新增这四项的自动输出。
- 验收以最终逐格裁切的正确对应、完整画面保护及固定尺寸、源域和风险预算为准；内部角色命名差异、
  已确认接触照片的共享边界本身不构成失败。共同输出须覆盖完整竞争集合，逐成员核验自身尺寸与权限；
  阶段收益与回退分别核验首选方案、保留提案、预算资格及安全自动批准；有共同根因证据的暂时回退
  可以保留，危险自动批准必须为 0。候选覆盖或测试通过不替代发布能力。
- 拓扑竞争审计分别重放各解释自身的原生角色权限、覆盖和连续性，不借用首选解释的 source W。
  十一项中的九个 Contact runner 在黄金比较中不安全，其中六个仍通过预算；现有坐标权限和完整
  覆盖不能替代独立的照片序号关联。最终补边后的独立重放闭合 S091 的已登记 Overlap 关联与 S094
  的 separator 原生宽度反证，分别保留为解释自身的 `contradicted`；原 Review 与完整竞争边界保持。
  完整 producer 账本保留 pair 之外及早期定位的全部成员；各成员从自身 fit 独立编译 W/H/Cross、
  邻接、固定输出和预算证明。完整共同窗口先要求未被明确物理反证否定的全部成员获得资格并确立相同固定尺寸来源；
  缺口不能冒充物理排除，成对窗口跨度不能替代全集证明。当前该验证不授予自动输出权限。
  成员自身的 W/H/Cross 前置资格不足时，保留完整证据并明确标记输出及预算未评估，不再物化下游几何；

  Cross 原子归属直接枚举全部极大可行解释，完整原始联合域、原 4096 次共享核验上限与拟合预检保持；
