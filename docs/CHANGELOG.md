## V5（开发中，尚未发布）

### 行为边界

- V5 只有一条 current-only production path。输入 format 必须由用户提供，count 可确认默认值或明确指定；
  空曝光格保留，任何必需 slot 不安全都会使整张 source 进入 `needs_review`。
- 每条 source 使用共同 W/H 和固定 `1.1W × 1.1H` 原图坐标窗口，四边 5% 留边包含基础保护；程序只选择
  位置。可见内容、物理边界、typed evidence、source/lane 安全与人工 reference 继续按架构合同核验。
- 独立 source W 收窄时，即使 canonical W 不变，缺失边界的 model/full 区间仍同步更新；原生边界、
  phase 状态与真实 runner 保留。已选唯一 enclosing-support pair 的中心先验按相同资格规则重新绑定
  当前 3 源观察集合，向外量化区间为 `[-0.003H, +0.010H]`。
- Nominal Grid 保留已证明接触边界对相邻 END/START 的两项角色绑定；共享边界仍是一份物理观察，
  不增加 rank。无合法 contact 的重复绑定继续拒绝，schema 或 solver 错误不再误报为物理 Grid 冲突。
  保留的 native 双边宽度完整区间若与格式物理范围不相交，资格阶段即拒绝该映射；原有安全诊断提案
  继续保留。区间相交的局部变化不被代表点或拟合 W 强行排除。
  共享边恢复合法拓扑竞争后，多解 source 进入 Review，保留完整竞争证据与未闭合原因。
- Nominal 输出联合投影重放全部原生位置锚点、共同尺度及邻接约束，避免边际 hull 组合出无法同时
  成立的保护状态；role 差分消去共用 local prefix，避免重复计算同一不确定性。直接边界坐标和完整
  区间保持。不同合法 Contact/Overlap topology 不再因支持数或 coverage 分离被当作唯一解。
  源截断 Review 类优先保留独立获权原生证据更完整的解释，投影失败与
  反证原样保留；无权弱线和相关重复观察不能提高该优先级。
  Phase 与 topology 歧义均按两份 retained fit 各自补全原生局部边界、传播联合约束与 Cross 支撑域；
  不共享另一解释的 W、不取消歧义或物理反证。
  独立原生 Review 按成功原生坐标、成功校准 Grid、失败原始解释分别保留四个端点角色类；不同几何
  依据不再因共享端点类别互相覆盖。失败与反证保留，原规范竞争及自动权限保持独立；新增实际重建
  工作逐次计入有界 receipt。
  最后补入原生边界后，保留解释分别重建自身邻接证明。唯一已登记伙伴的条件照片序号、原物理身份
  与完整宽度反证进入报告；不补 phase anchor、不增加 rank、不借用另一解释的 source W。新增工作
  固定至多两份并计入账本；已否定的 runner 不使未保留的其它解释自动消失。
- 只有真实 TIFF 外缘允许 source clipping；内部 authority 边界不能用缩小窗口绕过。Deskew 只在批准后
  整理，不参与检测或 Gate。Debug Analysis 复用同次检测事实，不取得裁切或自动输出权限。
- 正式 TIFF 只在整张 source 通过安全准入后发布；输出先写 staging，再原子发布到全新目录，保留既有目标。

### 验证边界

- 验收以最终逐格裁切的正确对应、完整画面保护及固定尺寸、源域和风险预算为准；内部角色命名差异、
  已确认接触照片的共享边界本身不构成失败。共同输出须覆盖完整竞争集合，逐成员核验自身尺寸与权限；
  阶段收益与回退分别核验首选方案、保留提案、预算资格及安全自动批准；有共同根因证据的暂时回退
  可以保留，危险自动批准必须为 0。候选覆盖或测试通过不替代发布能力。
- 拓扑竞争审计分别重放各解释自身的原生角色权限、覆盖和连续性，不借用首选解释的 source W。
  十一项中的九个 Contact runner 在黄金比较中不安全，其中六个仍通过预算；现有坐标权限和完整
  覆盖不能替代独立的照片序号关联。最终补边后的独立重放闭合 S091 的已登记 Overlap 关联与 S094
  的 separator 原生宽度反证，分别保留为解释自身的 `contradicted`；原 Review 与完整竞争边界保持。
  完整 producer 账本保留 pair 之外及早期定位的全部成员；各成员从自身 fit 独立编译 W/H/Cross、
  邻接、固定输出和预算证明。完整共同窗口先要求全部成员获得资格并确立相同固定尺寸来源；
  缺口不能冒充物理排除，成对窗口跨度不能替代全集证明。当前该验证不授予自动输出权限。
  成员自身的 W/H/Cross 前置资格不足时，保留完整证据并明确标记输出及预算未评估，不再物化下游几何；
  该成员仍属于全集，继续阻断共同窗口。单帧保护与报告转换复用相同事实，保持独立报告分支和安全判据。
  Contact 转授角色与原生角色分别保存，禁止共享线反哺 W，同时保留其独立原生一侧的完整 Frame 测量。
  跨解释共同尺寸使用所有具名成员认可的相同原生完整 pair 和独立直接 H；保留各成员原有条件几何，
  共同测量代表不相容时明确拒绝，不从区间交集中另选尺寸。各阶段共同窗口与历史全集分别验证全部成员和 slot。
  Cross 原子归属直接枚举全部极大可行解释，完整原始联合域、原 4096 次共享核验上限与拟合预检保持；
  新增实际分支、过滤、极大性与原始输入工作计数，超界不公开搜索前缀。
  Cross 支撑域按实际原生坐标核验已有 Overlap 的原 gap/delta 区间，避免拿 model 代表点误拒合法原生状态；
  无独立 Overlap 或实际状态超出原区间时继续拒绝。
- 对全部既有候选核验遗漏的唯一获权 separator 伙伴；仅原生完整可见宽度超过原物理上限时保留为
  关联反证，不补绑定、不调整排序、不借 source W。报告进入当前 schema 113，独立 Review 显示各解释的
  `geometry_basis` 并重放十二类完整映射。Coverage／continuity
  校验共用 typed owner，并从开发报告原证据重建，删除重复判据。
  最终保留解释的 `retained_adjacency_assessments` 同时出现在普通及 development 报告，从原登记事实
  逐份重放完整角色、伙伴、覆盖和连续性；删除记录、交换权限或伪造宽度与资格均拒绝。
- 开发报告的 broad、Cross line／family receipt 共用既有 typed 解码，删除重复字段装配及退役解码；
  保留完整关联、数值重算、权限和资源重放，拒绝数值字段中的布尔值。测试共用固定夹具，依赖版本只由
  冻结合同维护；按实际 pip／Homebrew 加载来源重新绑定黄金与性能证据。
- phase 求解按职责拆分并复用不可变准备事实；区域测量使用紧凑整数与有界列块，保留完整观察和判据。
  拟合合并秩与无约束解的分解，省去匹配不变及只越过 gap 时的重复求解；方向规范化与竖向工作区
  统计复用原数组视图，非连续 RGB 百分位采样不构造坐标向量，避免整图副本并保留像素、映射和连续
  输出。简单二维几何共用原生
  区间枚举与物理线域裁剪，联合投影复用同次相同方向的求解，保留完整可行域与实际工作计数。
  登记峰以数组索引替换逐像素 Python 列表，保留全部峰字段、极性分组、同值次序与定位保护。
  验证工具删除退役 runner，性能测量保留失败记录并拒绝覆盖已有 receipt。
- 开发排序用对扫描方向不敏感的源截断长度比例区分已有方案，并显式报告同一 task 中特征完全相同、
  黄金标签相反的候选组；评分仍不授予自动输出权限。
- 仿射采样在完全位于 source authority 内部的块使用等价的内部插值路径，外缘继续保留部分越界 tap，
  复用原有坐标和缓冲。选择结果的构造与撤回共用已有 typed model，删除重复字段装配。
- `tools/verify` 是工程、准确性、性能、平台和 Hook 的统一入口；开发 gold、诊断报告、CI 通过或安全
  Review 都不能替代架构第 14 节定义的 release gate。
- Development report 校验从各区域 contrast/texture 区间重建 separator material 状态和完整摘要，
  拒绝与实测区间矛盾的支持标签、遗漏区域的摘要和重复 observation。
- 实现 `f881e35c` 的完整开发黄金覆盖 110 项任务、106 个来源 SHA，分析错误与危险自动批准均为 0。
  同一 cohort 逐任务比较无回退：安全提案覆盖 110 项、安全且预算通过 91 项、首选安全 95 项、
  安全自动批准 15 项。正式 24-source mean 为 4.858 秒，满足 `<= 5s`；正常 Hook 的 1307 项测试
  （2 项跳过）及 12 项 CI 均通过。完整竞争验证仍不授予自动输出权限，发布检测 Gate 尚未闭合。
- 发布资格必须把 accuracy、TIFF/metadata、性能、安装、目标平台、打包和 Hook/CI 证据绑定同一最终
  release commit。V5 当前仍为开发预览，未创建 RC、tag、GitHub Release 或公开 ZIP。
